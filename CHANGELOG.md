# Changelog

## 1.0.0 — 2026-11-18

Initial release.

- 3D multiplayer table tennis (Three.js client, server-authoritative physics)
- Ranked matchmaking + private rooms + spectating
- Accounts (Argon2id), profiles, Elo leaderboard, match history
- PostgreSQL schema with migrations
- Docker Compose deployment, start/stop/backup/restore scripts
- REST API + WebSocket protocol, full documentation
- Test suite: physics, Elo, match rules, API integration
